# Direct an engaging camera-facing performance

Keep the presenter visible throughout each clip. Use one continuous shot with coherent setting, clothing,
lighting and camera behavior. Choose camera distance, placement and light from the conversational setting,
whether a casual phone, desk or intentional studio setup. Keep eye contact and intelligible sound;
do not add visible production equipment unless requested. More mobile camera work can fit an explicit brief;
do not introduce internal cuts, cutaways, montage, split screens or product-only shots.
For a product review or recommendation, proactively design meaningful holding, showing or supported use
in the same shot when it helps the explanation. The user need not explicitly request each gesture.
Keep verified product appearance, feasible handling and the presenter visible throughout.

Direct the response to the thought, not a gesture for every sentence. Specify gaze, emotional intention and
selective emphasis: a discovery can land through a brief pause and pleased expression instead of sustained
exaggerated excitement. Preserve recognizable features and natural skin texture over head turns.

A speaking reference may establish habitual expression and delivery only to the extent the model supports
that input. Verify whether reference audio actually influences voice. A matching face is not proof of a matching
voice. If exact vocal identity is essential and unsupported, explain the limitation before presenting a substitute.

Build each complete prompt around:

1. Actual reference attachments and their roles; identity and scene details to preserve or change.
2. Visible shot: crop, eyeline, setting, light, wardrobe, camera and permitted physical props.
3. Performance intention, reactions and meaningful gestures tied to selected phrases.
4. Exact dialogue in the commissioned language, separated from instructions and pronunciation guidance.
5. Supported duration, natural pace, brief lead/tail room, and complete sentence endings.
6. Continuous-presenter boundaries: no B-roll or cutaways. Specify exact planned native captions/labels
   from the Script Plan, or no added text for a clean take. Do not add unsolicited title cards or graphic logos.
7. Native audio direction: speech and useful room/product sounds, plus fitting light background music or an
   intentional unscored choice, its balance with the voice and its ending. See [music and sound](music-and-sound.md).

Distinguish an existing physical product label from an added graphic logo. Usually request supportive native
background music beneath clear speech. For a deliberate unscored take, explicitly request no background music
while retaining speech and useful natural sound. An API audio switch may control all audio together; use the
prompt to distinguish these layers and review the actual result. Do not import an inherited blanket music ban.

Use supported attachment notation returned by the tool, not invented tokens. A prompt saying "use my video"
without an uploaded reference does not condition the model on that video. Avoid accidentally literalizing
editorial language such as "show the app" into a floating screen or a prop in the room.

Use an existing accurate portrait or recording directly when it suffices. If a new starting still is necessary,
generate it through OpenArt MCP with an appropriate live image model and inspect identity, wardrobe,
hands, setting, crop, visible eyes and mouth before using it. Do not generate storyboards or supporting imagery
by default. Seedance remains the video generation route.

## Make an explanation persuasive within a continuous take

Begin with a viewer-relevant question or proposition. Connect the explanation to a visible product
detail or supported operation, then return attention to the viewer for the useful conclusion. Tie
gaze, emphasis and a meaningful handling task to the thought. A fixed camera can contain a discovery,
a closer look and a reaction; do not reduce every presentation to specifications and one palm gesture.
For a promotional request, integrate the appropriate spoken next action into the explanation.
Camera-facing delivery can be warm and personally engaging; it does not require a sales voice.
Use [recommendation writing](recommendation-writing.md) to develop the reasons before directing delivery.
Retain the continuous-presenter boundary and any explicit clean-footage requirements.

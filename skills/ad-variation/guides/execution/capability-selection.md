# Choose execution capabilities from the creative decision

This is an OpenArt MCP skill. Use OpenArt MCP for image, video and audio generation, including speech,
music or sound effects when needed and actually supported. Route every other needed operation that
OpenArt MCP supports through it as well. This requirement is distinct from the freedom to choose a
supplementary editing tool; it is not merely a model preference.

Map each operation to an OpenArt tool with [OpenArt execution](../../references/openart-execution.md),
read while planning, and inspect live capabilities and schemas before routing.
Use the selected account/workspace and existing authorization. A missing connection, expired access,
failed job or inconvenient limit is not evidence that OpenArt lacks the capability: report the specific
issue and resolve it without silently switching providers. Do not invent endpoint names or supported modes.

Choose supplementary tools only for operations OpenArt MCP does not provide, such as local assembly,
caption alignment or composition when those operations are absent from its live capabilities. Do not
replace supported OpenArt operations with another provider or a direct model API. This skill supplies
no fixed supplementary editor, transcription tool, command recipe, installation flow, project format
or bundled runtime. Start with the keep/change map and
determine which operations are needed: inspect media, transcribe/align accepted speech, generate changed
material, edit source ranges, place text, compose graphics, mix sound, render and review.

Use this routing boundary for every operation, including those discussed in the other craft guides.
An unchanged recording does not require new
video generation; a caption correction does not require a new presenter. Check supported inputs, timing,
audio, references, output limits and usable export paths before promising a result. Do not assume a video
reference also guarantees exact source editing or voice matching. Explain a consequential missing operation
rather than silently changing the commissioned result.

Before presenting the Script Plan, prepare the complete prompts for planned generation and the matching
edit/composition plan. Discover the selected model's real capabilities so the proposal is executable.
Apply the shared Seedance 2.5 Draft/full-quality defaults and approval workflow, taking request fields and
identifiers from the live form rather than a previous run. Resolve the named model through OpenArt MCP, not a direct
provider API. An edit using only accepted files does not need artificial generation to satisfy a mode.

Perform only the approved creative scope and required implementation. Preserve exact text and reference
roles, use actual supported controls and retain receipts. If automatic prompt rewriting cannot be disabled
when requested, disclose that limitation. Do not add unreviewed dialogue or on-screen text during execution.

When video delivery is requested, continue through actual assembly and review after approval. A strategy,
prompt, generated fragment or successful render status is an intermediate result. Use the other guides
for editorial judgment and report what unavailable capabilities prevent rather than claiming completion.

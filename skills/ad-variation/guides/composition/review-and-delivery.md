# Review the actual deliverable

Compare the export to the brief, treatment, and reference relationships. Review the complete video, then inspect difficult passages at higher detail. Save timestamped findings so fixes belong to the right source, timing input or edit.

Evaluate these dimensions when relevant:

| Dimension | Evidence to inspect |
| --- | --- |
| Completeness | Entire requested duration, all required words/scenes, correct ending, complete variant |
| Person and performance | Recognizable identity across poses, coherent voice, expression, gestures, lip sync |
| Reference relationship | Preserved constraints and meaningful adapted pacing/design, not merely similar ingredients |
| Product truth | Real labels/assets/states, supported claims, illustrative outcomes identified appropriately |
| Composition | Readable scale, hierarchy, crop, typography, caption placement, purposeful timing |
| Sound | Intelligible speech, clean joins, appropriate music/effects, no accidental doubling or clipping |
| Music intent | Planned BGM actually audible, fitting character and progression, clear speech/product sounds, coherent ending, intentional unscored exceptions |
| Technical export | Expected dimensions/frame rate/streams, decode success, no missing/black/frozen ranges |

Use probes and full decode checks for technical validity, frame grids for coverage, individual frames for typography/layout, and real playback with sound for timing and auditory judgment. Silence/black detection produces candidates for inspection, not automatic failures; a deliberate pause or black transition can be valid. ASR completeness is useful but does not replace listening.

For a controlled comparison, reuse the same accepted performance and product evidence while changing the production instructions or implementation. Keep generated-material quality separate from composition quality. If only a smoke test or planning exercise was run, label it that way; do not claim it validates arbitrary references or realistic raw-footage editing.

Deliver the complete video and requested variants through usable file links, with a concise description of the changes and any unresolved limitations. Retain the accepted files, relevant generation receipts and timing decisions needed to continue the task. Do not require an editable project, component package, material manifest, dependency inventory or rebuild instructions.

Show the actual media through the host's supported preview and provide a usable file link. Identify the accepted version and variants clearly. Keep review notes and unresolved defects separate from final filenames. State exactly what was verified and what still needs human or unavailable-tool review; avoid turning a renderer success into an unearned quality claim.

## Creative intent check

Play the whole result and record timestamped findings: does it develop as planned, does the person
react credibly to what they say, does product action add useful information, and does an ending hold
serve an actual purpose? A fixed camera can pass. Unmotivated stillness, repetitive posing or stiff
delivery cannot be accepted merely because fidelity or technical checks pass. Prompt compliance
does not establish video quality. Mark these checks unverified when playback is unavailable.

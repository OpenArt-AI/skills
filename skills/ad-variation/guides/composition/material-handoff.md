# Bring generated or supplied files into the edit

Retrieve accepted results as project media and continue editing, composition and rendering with the
available capabilities. Script and prompt writing remain creative responsibilities of this skill.

For each result, keep the exact prompt, model/mode, parameters, reference roles and identifiers, generation
receipt, terminal status, usable URL or local path and acceptance notes. Keep credentials out of working records.
Preserve original generated files alongside normalized or trimmed intermediates.

Check terminal success, expected resources, download completeness, actual streams and duration, and
visual/audio suitability. A thumbnail, result card or successful request alone does not prove the movie
exists or satisfies the plan. Partial success remains visible.

Import the actual file into the chosen editing workflow and retain its source-time relationship. Normalize
only as necessary and align speech when the edit or captions need it. A raw file is not automatically a
ready composition layer or trustworthy alignment result. Inspect prepared outputs before using them.

Keep the accepted files and any source ranges, crop or audio choices needed for the next edit. Reuse them rather than regenerating unaffected material. These are working records, not a required editable-project delivery.

# Preserve the right things while changing the work

Express the request as a **keep/change map** before choosing tools. Consider words, person, voice, gestures, timing, camera, setting, product, graphics, sound, and overall argument. Lock only what the user actually wants preserved. Unspecified details can follow the reference and treatment; ask when a decision would materially change the request.

Strict source editing and creative reference transfer need different evidence:

- For strict replacement, the source is the material being altered. Preserve the measured source duration, requested audio, actions, framing, cuts, and untouched regions. Supply actual source footage when the selected model requires it, and compare the result across the entire source. A newly staged performance is not evidence of an exact replacement.
- For a new message in a reference style, recover why the reference's delivery, cuts, and graphics work. Write the target's own argument and reconnect those relationships to its actual words and accepted performance. Copying source timestamps despite different speech usually loses the relationship being imitated.

A per-request model duration limit must not silently shorten the deliverable. Determine whether the selected model supports the required editing/continuity. If segmented generation is appropriate, divide at coherent boundaries, preserve overlap or boundary references where useful, reconcile audio, and assemble the full intended piece. Use [source-preserving edits](../composition/source-preserving-edit.md) for the source-clock ledger, overlap ownership, sound retention, and assembly. If an uninterrupted transformation cannot be preserved, describe the limitation before presenting an approximation as exact.

Revisions follow dependencies, not a catalog of named use cases. For a new opening, identify the opening's speech, performance range, visual response, and transition into the retained body. Generate only changed material when needed. If the new take is longer, either preserve a requested fixed-duration window with a suitable take or shift dependent downstream events. Re-align changed speech and check the seam, caption sequence, music, and final duration. Keep unchanged output selections explicit.

For variants, name the hypothesis each version tests and what is held constant. An alternative hook may change the promise or angle; a local graphic revision should not regenerate the presenter. Save distinct runs and complete exports, with a concise comparison ledger. Shared accepted material can remain one asset used by several runs.

Treat unseen reference types as combinations of behavior: dialogue turns, evidence reveals, persistent panels, full-frame performance, ranked items, physical demonstrations, or other relationships discovered in the source. Read the relevant craft and realize the requested behavior with the simplest suitable editing method. Do not reject a reasonable request just because its label does not appear in this Skill.

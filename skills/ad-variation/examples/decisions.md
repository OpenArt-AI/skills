# Three different creative decisions

## A recording with several false starts

The user has a 90-second raw explanation and wants a clear, concise version without changing the message. Keep the actual performance. Inspect all takes, recover the intended argument, and select coherent sentences. Preserve meaningful hesitation before a difficult claim; remove a repeated start that contributes nothing. Save source ranges, create an audiovisual edit, then align the accepted result. Add supporting evidence only where it helps the explanation. No image/video model request is necessary just because generation is available.

## A new product in the spirit of another advertisement

The user supplies a persuasive reference ad, a different person's speaking recording, and a software URL. The first video supplies the rhetorical and visual relationships; the second supplies identity and natural delivery. Inspect the actual product interface and evidence, develop the target message, then direct a new performance through a video-reference-capable model. Pass the actual identity recording, not only its filename in the prompt. Rebuild the product demonstration from observed UI. Place its reveals against the new accepted speech instead of copying the old ad's seconds. A full-width product canvas with occasional presenter returns may fit better than an inset.

## A different opening with the same body

The user likes an existing export but wants a skeptical opening instead of an enthusiastic question. Identify what the existing opening controls: its dialogue, performance, caption ranges, reaction shot, and transition. Keep the body, product evidence, and unrelated graphics. Direct or edit the new opening and measure its length. Shift/reproject the body where necessary, preserve source sampling, and inspect the join. Export the complete revised video, with a separate run preserving the original. The ability comes from understanding change dependencies; it needs no dedicated hook template.

In all three, the same intent, direction, composition, and execution knowledge applies in different proportions. A fourth request may combine these relationships or call for a different visual treatment.
